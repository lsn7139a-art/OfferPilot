# 🎯 面试题每日打卡系统

> 互联网大厂 + 具身智能赛道 面试题自动推送与进度追踪系统

## 📋 项目概述

本系统自动收集互联网大厂（字节、腾讯、阿里、美团、华为等）和热门具身智能公司（宇树科技）的招聘要求与面试题，每日通过飞书推送题目，内置进度追踪Agent，形成"推送→学习→反馈→优化"的闭环。

## 🚀 使用方式

### 每日流程
1. **早上9:00** — 系统自动推送3道题到飞书群「面试题每日打卡」
2. **学习答题** — 完成题目，查看answer_hint中的解题思路
3. **回复进度** — 在本对话中回复进度，例如：
   - `"完成1,2 第3题不会"` → 标记第1、2题完成，第3题跳过
   - `"进行中2"` → 标记第2题进行中
   - `"查看进度"` → 查看学习统计
   - `"复习算法"` → 切换复习方向为算法
   - `"目标公司 字节,宇树"` → 设置目标公司
4. **晚上21:00** — 系统发送晚间提醒，督促完成当日题目
5. **每周日10:00** — 系统自动更新题库，补充最新面经

### 进度Agent指令大全

| 指令 | 示例 | 功能 |
|------|------|------|
| 完成 | `完成1,2,3` / `1,2做完了` | 标记题目完成 |
| 跳过 | `跳过3` / `第3题不会` | 标记题目跳过 |
| 进行中 | `进行中2` / `2在做` | 标记题目进行中 |
| 查看进度 | `查看进度` / `统计` | 查看学习统计 |
| 切换方向 | `复习算法` / `学操作系统` | 优先推送某方向 |
| 目标公司 | `目标公司 字节,腾讯` | 设置目标公司 |

### 手动运行脚本

```bash
# 生成今日题目（不推送）
python scripts/daily_push.py

# 推送今日题目到飞书
python scripts/feishu_push.py --mode daily

# 发送晚间提醒
python scripts/feishu_push.py --mode evening

# 同步学习进度
python scripts/progress_sync.py "完成1,2 第3题不会"

# 查看题库统计
python scripts/update_questions.py stats
```

## ⚙️ 配置说明

编辑 `config.json` 可调整：
- `question_selection.daily_count`：每日推送题数（默认3）
- `feishu.chat_id`：飞书群聊ID
- `schedule`：各定时任务的cron表达式

编辑 `data/progress.json` 可调整：
- `preferences.daily_count`：每日题数
- `preferences.target_companies`：目标公司（影响选题优先级）
- `preferences.preferred_categories`：偏好方向

## 🔄 智能选题策略

每日选题基于以下因素加权：
1. **目标公司优先** — 目标公司的高频题加分
2. **薄弱领域加权** — 完成率低的方向优先推送
3. **进行中优先** — 标记为进行中的题目优先出现
4. **难度配比** — Easy 30% / Medium 50% / Hard 20%
5. **随机扰动** — 避免每天题目完全相同
6. **去重** — 已完成/跳过的题目不再推送
