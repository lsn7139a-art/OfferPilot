## 第5页：解决方案 —— OfferPilot是什么

**标题：** OfferPilot = 岗位驱动 + 自适应学习 + 飞书闭环

**三大核心功能：**

1. **🎯 岗位驱动的精准选题**
   - 每日推送1个具体岗位（含JD详情+链接）
   - 智能匹配3道与该岗位高度相关的面试题

2. **🔄 自适应学习引擎**
   - 未完成 → 自动延期，换岗位不换题
   - 已完成 → 自动替换同方向新题
   - 薄弱领域加权，间隔复习

3. **✅ 飞书生态闭环**
   - 群消息推送 + 待办任务 + 状态回传
   - 加群即用，无需下载APP

## 第9页：自适应选题算法

**标题：** 核心算法：让每一道题都恰到好处

**打分机制：**

| 维度 | 权重 | 说明 |
|------|------|------|
| 岗位分类匹配 | +8分 | 题目分类与岗位要求匹配 |
| 岗位标签匹配 | +4分 | 题目标签与岗位技术栈匹配 |
| 岗位公司匹配 | +5分 | 题目出现公司与岗位公司一致 |
| 薄弱领域加权 | +3分 | 用户薄弱领域的题目优先 |
| 进行中优先 | +6分 | 未完成的题目自动延期 |
| 随机扰动 | 0~1分 | 增加多样性，避免重复 |

**结果：** 按分数排序后随机选择，兼顾精准性和多样性。

## 第10页：核心创新点

**标题：** 四大创新，构建竞争壁垒

1. **🎯 岗位驱动的精准匹配**
   - 从JD反推知识点，告别盲目刷题
   - 每道题都知道"哪个岗位会考"

2. **🔄 基于待办状态的自适应闭环**
   - 用户点"完成"→系统自动检测→动态调整
   - 未完成延期，已完成替换，真正因材施教

3. **💰 零成本无服务器架构**
   - GitHub Action + 飞书API，运行成本≈0
   - 极低部署门槛，易于大规模复制

4. **📊 多源数据结构化整合**
   - 岗位库+题库+公司库三库关联
   - 数据资产持续积累，为AI分析奠基

## 可能被问到的问题（提前准备）

1. **Q：和LeetCode比，你们的优势是什么？**
   A：LeetCode是通用题库，我们是岗位驱动的精准匹配+自适应学习，用户知道每道题和目标岗位的关系。

2. **Q：飞书API如果收费或限制怎么办？**
   A：我们做好了接口封装，预留了微信/钉钉等多平台推送能力，不依赖单一平台。

3. **Q：用户为什么愿意付费？**
   A：免费版提供基础价值，付费版提供AI解析、全量题库、数据报告等不可替代的功能。

4. **Q：题库的版权问题怎么解决？**
   A：题目来自公开的LeetCode/牛客等平台，我们做的是整合和匹配，不生产题目内容。

5. **Q：你们的技术壁垒在哪里？**
   A：自适应选题算法、岗位匹配算法、持续积累的用户学习数据，这些都是越用越准的。

6. **Q：为什么用飞书而不是微信？**
   A：飞书开放平台API更完善，待办/日历/消息一体化，适合做学习闭环；微信公众号API限制较多。

7. **Q：你们的收入预测是不是太乐观了？**
   A：这是保守预测，基于5%的付费转化率；实际如果做到10%转化率，收入会翻倍。

8. **Q：如果大厂做类似功能怎么办？**
   A：大厂有流量优势，但我们更专注、更灵活；我们会快速迭代，建立数据和用户壁垒，深耕细分市场。
